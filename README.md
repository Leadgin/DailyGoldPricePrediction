This is Assignment for BMDS2003 Data Science. 

Project Overiew:
This project analyzes and predicts daily gold prices using machine learning regression models.
The dataset contains Daily Gold Price (2015–2025) time series data obtained from Kaggle:

Dataset: 
Daily Gold Price (2015-2025) Time Series
https://www.kaggle.com/datasets/nisargchodavadiya/daily-gold-price-20152021-time-series

To run the app,can be run through app.py.

Machine Learning Model used:
The following models were trained and evaluated:

1. Elastic Net
2. Linear Regression
3. Random Forest Regression
4. XG Boost Regression

The Random Forest Regression model achieved the best performance
